# Вход в блог с лендинга — дизайн-решение

> Прожарка: 2026-04-19. Статус: **все решения приняты, ждёт финального согласования визуала**.
> Контекст: на `learn-portugues.ru/` нет входа в блог. Первая статья `/ciple-a2/` живая, но недоступна с главной.
> Мокап: [блог-мокап.html](блог-мокап.html) — открой в браузере для финального согласования.

## Принятые решения

### 1. Цель блог-секции — поэтапно
- **Фаза 1 (сейчас, 1 статья)**: footer-блок "Читать по теме" → только SEO crawl paths от лендинга к статьям.
- **Фаза 2 (при 3-5 статьях)**: развернуть полноценную секцию на лендинге → конверсия "лендинг → статья → курс".

**Почему не сразу секция:** одна карточка = пустая витрина, отвлекает от главной CTA "Открыть первый урок". Секция работает только при 3+ статьях.

### 2. URL-стратегия статей — flat без хаба
- Статьи живут в корне: `/ciple-a2/`, `/portugalskij-ili-ispanskij/`, `/grammatika/` и т.д.
- **Хаб-URL (`/blog/`, `/stati/`) не создаём** — SEO-вес не размывается, одна статья не требует index-страницы.
- Когда фаза 2 наступит, секция на лендинге сама играет роль хаба.

### 3. Размещение секции на лендинге — после CTA, перед Footer
```
Hero → Core Value → FAQ → Comparison → CTA → [БЛОГ-СЕКЦИЯ] → Footer
```

**Почему:** лендинг — конверсионная машина, блог — вторичный путь для не-конвертнувшихся. CTA показана → если пользователь не кликнул → ловим его через "почитать по теме". Стандартный паттерн "content marketing footer" (Intercom, Stripe, Notion). Секция физически соседствует с футер-ссылками на Privacy/Terms — композиционно смыкается.

**Почему не другие:**
- A (после Hero): крадёт конверсию, Hero = "что это?", сразу блог = "всё ещё продаём".
- B (между Comparison и CTA): размазывает путь к CTA.
- D (тонкая полоска над футером): это просто C минималистичнее, эволюционно превращается в C.

## Фаза 1 — футер-блок (deploy сейчас)

### Паттерн (вариант E из прожарки) — полоска НАД футером

Новая мини-секция между CTA и футером:

```
...секция CTA "Начните сейчас — это бесплатно" ↑

ДАЛЬШЕ ПО ТЕМЕ
→ CIPLE A2 — как сдать на ПМЖ

Footer:
🌐 Portugues
© 2026 Portugues.   Privacy · Terms
```

**Характеристики:**
- Фон: `var(--background)` или `var(--muted)` — отделить от секций --card.
- Label: "ДАЛЬШЕ ПО ТЕМЕ" (стиль `.label`, caps, JetBrains Mono, primary color).
- Ссылки: список с arrow `→`, текст = заголовок статьи (SEO-значимый анкор).
- Padding: 48-64px вертикальный, совпадает с `.section`.
- Эволюция: эта же секция расширяется в фазу 2 — просто заменяем список на card-grid.

## Фаза 2 — полноценная секция (deploy при 3-5 статьях)

### Структура

```
┌─ section --bg ───────────────────────────────────────────────┐
│                                                              │
│            МАТЕРИАЛЫ                (label)                  │
│    Разобраться в теме глубже         (h2)                    │
│    Статьи по грамматике, сдаче экзамена, выбору курса       │
│                                         (subtitle)           │
│                                                              │
│   ┌────────────┐  ┌────────────┐  ┌────────────┐             │
│   │ [icon/bdg] │  │ [icon/bdg] │  │ [icon/bdg] │             │
│   │ H4 title   │  │ H4 title   │  │ H4 title   │             │
│   │ body-sm    │  │ body-sm    │  │ body-sm    │             │
│   │ Читать →   │  │ Читать →   │  │ Читать →   │             │
│   └────────────┘  └────────────┘  └────────────┘             │
│                                                              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### Элементы
- **Section**: `section section--bg` (фон `--background` серо-белый, отделяет от --card соседей).
- **Label**: "МАТЕРИАЛЫ" (стиль `.label`).
- **H2**: "Разобраться в теме глубже" (или альтернатива — пока не утверждено).
- **Subtitle**: краткое описание, что там за контент.
- **Grid**: `card-grid` (auto-fit minmax 280px) или `card-grid--3` при 3-5 статьях.
- **Card**: существующий `.card` паттерн (M3 elevated) — `background: --card`, padding 24px, радиус 12px.
- **CTA-ссылка карточки**: "Читать →" в конце или вся карточка кликабельна (решить отдельно).

## Закрытые вопросы (фаза 2 — детали карточки)

### ✅ Вопрос 5 — формат карточки = (A) без картинок
Icon-circle + цветной бейдж рубрики + H4 заголовок + body-sm тизер. Консистентно с Core Value section. Иерархия через цветные бейджи, не через thumbnail. Причина: SEO-трафик приходит в статью напрямую из выдачи — thumbnail на лендинге не окупает +60 мин продакшна на статью.

### ✅ Вопрос 6 — label "МАТЕРИАЛЫ" + H2 "Читать по теме"

**4 бейджа-рубрики:**
| Бейдж | Цвет (token) | Статьи |
|---|---|---|
| ЭКЗАМЕН | blue (`--color-info`) | CIPLE A2 — как сдать |
| ВЫБОР ЯЗЫКА | orange (`--color-warning`) | Португальский или испанский, Европейский vs бразильский |
| ГРАММАТИКА | green (`--color-success`) | Грамматика, Артикли, Ser/estar, Спряжения |
| ПРАКТИКА | red (`--color-error`) | Фразы для жизни, Как выучить |

### ✅ Вопрос 7 — CTA внутри карточки = (C) вся карточка кликабельна + кнопка "Читать →"

Паттерн: `<a class="article-card">` оборачивает всю карточку, внутри — бейдж, H4, тизер, `.article-read` с текстом "Читать →". Hover-effect `translateY(-2px)` + elevation — уже есть в DS. `aria-label` на anchor для accessibility.
