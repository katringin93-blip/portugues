## Что такое SEO простыми словами

Люди ищут в Яндексе "как выучить португальский" — и твой сайт появляется в результатах. Чем выше — тем больше людей зайдёт. Для этого нужно:

1. Чтобы Яндекс **знал** о твоём сайте (регистрация, sitemap) — ✅ сделано
2. Чтобы на сайте были **страницы**, которые отвечают на вопросы людей
3. Чтобы Яндекс **доверял** твоему сайту (качество, поведение посетителей)

Первый трафик из Яндекса появится через **1–3 месяца**. Это нормально для нового домена.

## Этап 2: Создать SEO-страницы (основная работа)

### Зачем нужны отдельные страницы

Сейчас весь курс — это SPA (одностраничное приложение) с адресами вида `/course/#/lesson/5`. Яндекс **не индексирует** страницы после `#` — он видит только одну страницу `/course/`.

Поэтому нужно создавать **отдельные статические HTML-страницы** для каждой темы, по которой люди ищут в Яндексе. Каждая такая страница — это точка входа из поиска на твой сайт.

### Какие страницы создавать

Ниже — список страниц, отсортированных по приоритету. Каждая страница отвечает на конкретный поисковый запрос.

|---|---|---|
| Курс европейского португальского с нуля | "курс португальского онлайн", "учить португальский с нуля" | `/kurs-portugalskogo/` |
| Европейский vs бразильский португальский | "отличия европейского и бразильского португальского" | `/evropejskij-vs-brazilskij/` |
| Как выучить португальский самостоятельно | "как выучить португальский язык самостоятельно" | `/kak-vyuchit-portugalskij/` |

### Как должна выглядеть каждая SEO-страница

Каждая страница — отдельный `.html` файл (как `privacy.html` или `terms.html`). Структура:

```
1. Заголовок H1 — содержит ключевой запрос
2. Вводный абзац — о чём страница (2–3 предложения)
3. Содержание — разбитое на H2/H3, с таблицами, списками, примерами
4. Блок "Попробуйте в курсе" — ссылка на соответствующий урок
5. FAQ — 2–3 частых вопроса по теме (как на лендинге)
```

**Важные правила:**
- **Title** (заголовок вкладки): до 60 символов, ключевое слово в начале
  - Пример: `Артикли в португальском языке — правила и примеры`
- **Meta description**: 1–2 предложения, до 160 символов, с призывом
  - Пример: `Определённые и неопределённые артикли в европейском португальском. Таблица, правила, примеры. Бесплатный курс с упражнениями.`
- **URL**: латиницей, через дефис, без цифр и спецсимволов
  - `/artikli-v-portugalskom/` — хорошо
  - `/unit/2` — плохо
- **Контент**: минимум 1000 слов, с таблицами и примерами. Не лить воду — Яндекс за это наказывает
- **Ссылка на курс**: в конце каждой страницы — кнопка "Начать урок" → `/course/#/lesson/N`

## Этап 3: Оптимизация того, что уже есть (1 раз)

### 3.1. Добавить Schema.org разметку

Schema.org — это специальная разметка в HTML, которая говорит Яндексу "это курс", "это FAQ", "это автор". Яндекс использует её для красивых сниппетов в выдаче и для нейроответов Алисы.

**Что добавить на лендинг:**
- `Course` — описание курса (название, язык, количество уроков, цена: бесплатно)
- `FAQPage` — вопросы-ответы из аккордеона
- `Organization` — информация о проекте

> Я могу добавить эту разметку в код — скажи когда.

### 3.2. Мета-тег keywords на лендинг

Добавить в `<head>` лендинга:
```html
<meta name="keywords" content="португальский язык, курс португальского, европейский португальский, учить португальский, A2 португальский, португальский для начинающих">
```

### 3.3. Проверить скорость загрузки

1. Открой https://pagespeed.web.dev

3. Посмотри оценку для мобильной версии

## Чего НЕ делать

- **Не покупать ссылки** на биржах — Яндекс за это наказывает фильтром
- **Не накручивать посещения** — Яндекс определяет ботов и банит на годы
- **Не копировать чужие тексты** — только уникальный контент
- **Не лить воду** — Яндекс наказывает за тексты без полезной информации
- **Не переоптимизировать** — не вставлять ключевые слова в каждое предложение. Пиши для людей, не для робота
- **Не делать одинаковые шаблонные страницы** с минимальными отличиями — каждая страница должна иметь реальную ценность
